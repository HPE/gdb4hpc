Revision 1.1  2002/06/26 17:48:59  greg
Created CHANGES file.

Modified dataflow graph to remove use of AIFSub() for comparisons. The
	graph now calls the user supplied function CompareData() which
	must perform the comparison (using AIFCompare()) check for
	exit conditions and display the results of the comparison, if
	necessary. CompareData() returns 1 if the graph is to continue
	or 0 if it should exit.
Modified PrintGraph() to support printing the graph in DOT format.
Added new COMPARE node.
Changed assert_t (assert.h) to ainfo_t. This is now used to record
	information about the assertion that is passed to CompareData()
	in order to determine exit conditions, display format, etc.
	Removed log messages from source files.
