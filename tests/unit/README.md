# gdb4hpc Unit Tests

All of the instructions here can be executed automatically by the `runBuildUnitTest.sh` script in the root directory.

## Building

The makefile in this directory is generated by the base gdb4hpc configure script (called in `runBuild.sh`). The tests depend on the build state of gdb4hpc since they use some of the libraries built by the gdb4hpc build process.

After that, run `make` in this directory to build the unit tests.

Make sure the Google test submodule is checked out.

## Running

Run `./unit_tests`.
